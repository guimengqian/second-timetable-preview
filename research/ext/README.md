# research/ext：外部数据加固与外链核验（2026-11-20）

本目录有两份交付：

| 文件 | 内容 |
|---|---|
| `external_data.csv` | A 部分：61 行外部数据（麦可思、阳光高考/教育部、政策条款、招聘平台报告），含原文 URL、引文和口径 |
| `link_audit.csv` | B 部分：72 行外链核验，覆盖 `index.html` 正文中的 30 个外链，以及 `story-data.json` / `data.json` 中 53 条招聘启事与项目底表引用的链接 |
| `raw/` | 抓取的原始网页/PDF/接口返回，均视为不可信数据，只用 `python3 -I` 读取 |

## 字段说明

`external_data.csv` 的 `verified` 取值：

- `yes`：在所给 URL 上逐字找到引文。URL 是发布机构本身、权威媒体对发布内容的直接报道，或者书籍原文。
- `partial`：只在二手、自媒体或转载稿中找到；或原链接已失效，改用全文转载核对；或数值是编者根据原文算出的合计。
- `no`：查不到。保留这一行，是为了说明“查过、没有公开数据”。

`link_audit.csv` 的 `status`：`ok`（可打开，正文转述一致）、`mismatch`（可打开，但正文数字、引文或来源归属与原文不一致）、`dead`（链接本身已无法打开原文）、`unreachable`（本次未出现）。

## 方法

1. **静态页面**：用 curl 抓取（带重试），存入 `raw/links/`、`raw/a*/`，再用 `tools/totext.py`（在 site 目录之外）转成 `.txt` 后检索比对。PDF 用 pypdf 解析，xls/xlsx 用 xlrd/openpyxl 解析。
2. **JS 渲染的招聘页**：
   - 腾讯、字节、快手、哔哩哔哩、21 世纪经济报道（campus.sfccn.com）通过官方公开接口取得岗位详情，返回值存于 `raw/api/`。
   - 美团、小红书、网易、京东、虎嗅、微信，以及阳光高考（会返回 HTTP 412 反爬），用浏览器实际打开后读取页面文本。
3. **教育部附件 1**：逐行解析 1996 行。备注中含“调整”的 157 行视为调整门类或年限，其余 1839 行为新增，与公告数字一致；再按专业代码 0503 统计。
4. **阳光高考**：在浏览器内对同源接口 `/zyk/zybk/specialityDetail/{id}` 和 `/zyk/zybk/ksyx?specId={id}` 取数，快照见 `raw/a5/chsi_0503_snapshot.json`。

## A 部分要点

- **麦可思**
  - 2023—2026 版本科红牌名单里没有新传类专业。
  - 新传类唯一的预警是“广播电视学”，进入 2025 版黄牌，但只有自媒体转载（M05、M06），未找到麦可思原文。
  - 分专业类数据来自《2023 年中国本科生就业报告》全书 PDF（第三方 OSS 托管，属受版权保护书籍，引用时请标书名和表号）：2022 届新闻传播学类毕业去向落实率 84.8%，毕业半年后月收入 5792 元。新增和撤销专业数也出自该书：2018—2022 年网络与新媒体新增 155 个点，广告学撤销 46 个点。
  - 2024—2026 版的新传单专业数值（收入、相关度）在公开渠道查不到（M21）。
- **阳光高考**（统计截止 2025-12-31）
  - 毕业生规模：网络与新媒体 2.8 万—3.0 万人，已超过新闻学的 2.6 万—2.8 万人。
  - 有在籍学生的院校数：网络与新媒体 415 所，新闻学 324 所。这是学籍口径，不等于教育部专业布点数。
  - 新传类全国专业布点总数查不到官方分类口径（S21）。
- **政策**
  - 最直接的条款是教科信〔2026〕1 号《“人工智能+教育”行动计划》第（二）条：“优化传统学科专业人才培养方案，指导高校开设人工智能交叉融合课程”。第（四）条提到微专业、微证书。
  - 新闻传播专门文件最近的仍是教高〔2018〕7 号（卓越新闻传播人才 2.0）。2024—2026 年未检索到新的专门文件（P10）。
- **招聘端**
  - 猎聘：2025 上半年“明确要求掌握 AI 工具的职位”同比增长 149.41%，新媒体运营、视频编辑进入要求 AI 工具的 TOP20 职类；2026 年开工首周此类岗位同比增长 215.61%。
  - BOSS 直聘：AI 相关岗位月均新发职位数同比增速 2023/2024/2025 年分别为 8.5%/36.5%/74.1%。
  - 三家平台都没有公布“新媒体/内容岗中要求 AI 或数据技能的比例”（R09）。

mismatch（6 条）：

1. **人民日报社公告**：正文加引号的“专业条件按最高学历对应专业把握”不是原文措辞。原文为“岗位要求的专业条件均为报名应聘人员获得的最高学历所对应专业”。
2. **北京高校停招**：正文说“暂未查到北京高校停招新传类专业的官方公示”，但正文自己引用的清华页面（2023-11-22）写有“广告学，不招生”，新闻学“仅面向在校生设置辅修学位”。
3. **人大案例卡**：“传播学核心课程含‘计算传播’”在所链的人大广告学页面中找不到。
4. **中传传播学主要课程**：应为 25 门（13+12），图中写 26 门。
5. **中传 16 专业图的 tooltip**：“摄影并入影视摄影与制作”出自南方财经，不是人民网。
6. **中传 16 专业的“7 个经管理工类”**：人民网所列的 2025 拟撤销 7 个专业，与中国蓝观察所列名单有 4 个不一致；人民网也没有说明这 7 个属于 16 个之内。

dead（2 条）：澎湃美数课“数据编辑”（mkt-07）、新京报我们视频“策划报道组实习生”（mkt-17）的微信链接缺少 `sn` 参数，curl 和浏览器打开都显示“参数错误”。
